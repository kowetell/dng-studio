Aplikasi memeriksa ukuran file dan dimensi terlebih dahulu, lalu menjalankan konverter DNG tanpa mengubah lebar atau tinggi sumber.

01 / PILIH

Masukkan foto

02 / PROSES

Buat LinearRaw DNG

Konverter membuat DNG dari data RGB yang tersedia. Warna atau metadata tertentu bisa berbeda karena format sumber bukan data sensor RAW.

03 / SIMPAN

Unduh hasilnya

File diberi ekstensi .dng dan nama dasarnya mengikuti file sumber. Setiap foto dapat dikonversi dan diunduh secara terpisah.

Pertanyaan umum

Apakah JPEG bisa diubah menjadi DNG RAW kamera yang benar-benar asli?

Tidak. JPEG, PNG, dan WebP tidak berisi sampel sensor asli yang diperlukan untuk memulihkan RAW kamera secara persis. Web ini membuat synthetic LinearRaw DNG; itu tetap berbeda dari RAW yang diambil langsung oleh sensor kamera.

Apakah resolusi dan rasio berubah?

Aplikasi tidak melakukan resize atau crop. Nilai lebar × tinggi dan rasio aspek sumber dikirim sebagai informasi pemeriksaan. Normalisasi warna/bit depth dapat terjadi untuk format masukan tertentu, dan bagian transparan diratakan ke warna putih.

Mengapa mesin konversi belum siap?

Antarmuka web memerlukan mesin `image2dng` di komputer/server tempat aplikasi berjalan. Jalankan `setup.sh` sesuai README.md, lalu mulai aplikasi dengan `start.sh`. Membuka file HTML secara langsung tidak menjalankan backend konversi.

Apakah foto saya diunggah ke internet?

Dalam pengaturan bawaan, aplikasi berjalan di `127.0.0.1` pada komputer Anda sehingga file dikirim ke backend lokal. Jika pengelola memasangnya di server publik, file diproses oleh server tersebut. Jangan gunakan pada situs yang tidak Anda percayai untuk foto sensitif.
